# Soggy Pigeon

Play supported retro games online with one press of Search: the app pairs you
with another player and launches the game. Direct connection when the networks
allow it, server relay when they do not. Rollback netcode with an adaptive
delay controller keeps input delay low on a good connection.

## Download

Grab the installer from [Releases](https://github.com/BrendleFly/Soggy-Pigeon/releases).
It installs per user (no administrator rights, no .NET runtime needed) and
never includes games: the app finds and launches the ones already on your
computer.
